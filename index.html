Alignment Rule

Use the official BC curriculum pages while planning. Paste the exact Big Ideas, Curricular Competencies, and Content you will teach, then include the source URL and access date.

The exported document includes a source section so future readers can verify the plan against the BC curricular documents.

Planning Workspace

Draft mode: generate anytime. Blank fields appear as “To be completed” in the plan.

1. Teaching & Learning Context

Define the learning context (Grade-level, Subject Area, Number of lessons, etc.) and learner profile.

2. BC Curriculum Alignment

Paste or summarize from the official BC curriculum page for the selected grade and area of learning.
Choose a grade, area, and course to load any standards currently built into this tool. Always verify against the official BC curriculum page linked above.

3. Assessment Plan

Connect assessment evidence to Curricular Competencies and make criteria visible to students.

4. Learning Design

Use backward design: start with evidence of learning, then plan experiences.

5. Accessibility, Differentiation, Universal Design for Learning

These checks are carried into the exported plan to support accessible implementation and accessible documents.

6. Other Considerations

Add any planning notes that do not fit elsewhere.

7. Save Draft or Download

Generate a semantic HTML plan, print it, or download an HTML document that can be opened in Word or converted to tagged PDF.

Save draft files in a OneDrive or Google Drive synced folder to reopen them later on another device.
